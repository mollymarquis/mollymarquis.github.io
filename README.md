# Molly Marquis - Portfolio

Personal marketing portfolio site built with HTML, CSS, and vanilla JS.

## To deploy on GitHub Pages

1. Create a new repo on GitHub named `mollymarquis.github.io`
2. Upload all files in this folder to that repo
3. Go to **Settings > Pages**, set source to **main branch / root**
4. Site will be live at `https://mollymarquis.github.io`
